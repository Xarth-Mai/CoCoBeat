# 界面文案

首批 13 个语言变体对应同名 JSON，语言顺序、自称、字体和旗帜见 [正式需求](../../todo/02a-runtime-settings.md#国际化)；目录作为程序界面源代码随项目使用 MPL-2.0，原始字体与旗帜许可分别保留在相邻目录

所有 catalog 使用相同键与命名占位符，参数只替换一次，键码、P1/P2、路径及 CoCoBeat 保持原值；菜单、HUD、设置、通知和玩家可见错误按当前语言呈现，详细技术错误保留在开发日志，CLI 与日志不翻译

`en-US` 与 `en-GB` 独立保存，通用措辞可以相同；`zh-TW` 与 `zh-HK` 使用对应地区用词和字体；`es-419` 保持拉美西语语义，语言图标当前使用墨西哥旗帜

首次使用系统首选语言，未支持的语言回退 `en-US`；保存后的明确选择跨启动保持，语言与显示设置共用应用、取消和预览确认流程

修改文案后运行 runtime 的 i18n 窄测，检查键与占位符一致，并将实际值写入 UTF-8 临时文本，使用 `python3 assets/fonts/verify.py --text <locale> <file>` 检查对应字体字形；缺字检查与自动翻译校对不能替代母语使用者验收
