## 本次修订

按用户最新要求采用 Adobe 说明的 follow-through / overlapping 动作原则：在移动阶段就产生拖拽和水平剪切，主体于 6.60 秒停下后，Co1、Co2、Beat 延续已有运动，依次回弹归位；原先到位后停顿 0.10 秒再单独轻弹的时序已移除

主 UI 矩形在 6.60 秒后位置和尺寸完全固定；三组分别延后 0 / 40 / 80 ms，正向峰值为 6.66 / 6.70 / 6.74 秒，反向幅度为 15%，7.12 / 7.16 / 7.20 秒归零；眼睛、高光和颜色场跟随所属字组，菜单眼神循环及三个落点音效保持原样
