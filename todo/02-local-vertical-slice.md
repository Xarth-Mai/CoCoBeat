# 02 · 64 秒同机双人

前置：01。先用手写内容，不引入 media/stage generator/net。

- [ ] 原创可复现 64 秒音乐、独立帧标注、少量手写 Anchor；填写资源来源。
- [ ] 分段：0–8 秒定向，8–24 秒自由模仿，24–40 秒稀疏落点，40–48 秒留白，48–60 秒共同释放，60–64 秒结束。
- [ ] 一个逻辑 Hit、每位玩家可替换的物理绑定、稳定输入身份和 epoch。
- [ ] 初版 Windows/Linux 同时运行；支持双人键盘、双手柄与键盘＋手柄。
- [ ] 手柄加入/玩家归属、菜单确认/返回/暂停、重绑定与热插拔；重连不换玩家、不产生幽灵 Hit，单次按下不按渲染帧重复触发。
- [ ] Judge、带进度水位的一对一 Free Sync、Anchor Sync 与有界 Resonance。
- [ ] 测试等距/等边界候选、重复输入、交付重排、静默、连点和 Anchor/Free 去重。
- [ ] 两个简单 3D 小精灵、立即本地反馈、可辨识同伴声音/轨迹、FeedbackDirector 与最小 HUD。
- [ ] 记录每个输入、内容/规则/构建身份，并通过同一个 core 重放。

退出条件：同一输入回放在 60/144 Hz 和渲染卡顿下最终结果一致；Windows/Linux 均能用键盘或手柄完整体验并回放 64 秒。手写场景足够，不等待自动内容管线。
