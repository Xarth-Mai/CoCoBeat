# 产品与 V1 边界

CoCoBeat 是一个包裹在游戏里的双人节奏乐器。体验循环是：听见 → 预期 → 动作 → 立即感知自己的结果 → 感知同伴 → 调整 → 汇合 → 释放。
这是一项需要实验验证的设计假设，不是由研究报告直接证明的游戏乐趣。

V1 面向 Windows/Linux 桌面，先同机双人，之后才做可直达地址的 QUIC IP-direct。Bevy 负责 3D 与 UI，Kira 负责播放，Symphonia 负责导入，OxiMedia 的 MIR/audio 模块通过自有数据契约接入。每项库的能力和兼容性在接入时验证。

Windows（MSVC）和 Linux 是初版同步交付的平台，不把 Linux 留到后续移植；两者构建目标均包含 x86-64 / ARM64，不做 32 位。键盘与手柄是初版输入范围，必须支持双手柄、键盘＋手柄和双人键盘；包含菜单导航、玩家分配、绑定与热插拔，具体验收见 [平台与输入](platform-input.md)。

画面是雨夜霓虹和原创柔软 3D 小精灵：暗环境保留表现余量，真实的共同动作才触发更完整的光、声与空间响应。轨道是音乐时间的空间化，不是跳跃碰撞游戏。角色根位置由 SongTime 驱动。

V1 不做 Steam、FFmpeg、密集自动谱、自由演奏的隐藏正确率、按 Sync 数量排名、通用 NAT 穿透或多套媒体/网络 fallback。

第一份内容是手写的 64 秒音乐和少量 Anchor。观察玩家是否主动听见同伴、模仿、允许沉默、区分单人和共同反馈、把 Anchor 当成共同目的地。不能用自动 MIR、更多特效或曲库规模掩盖核心体验没有成立的问题。
