# 资源与许可证

项目代码使用 MPL-2.0；不创建 MIT/Apache 双许可证文件。外部依赖保留其自身许可证。当前依赖清单见 [THIRD_PARTY.md](../licenses/THIRD_PARTY.md)。

素材、音乐和数据不自动继承代码许可。每个新增资源在 [ASSET_PROVENANCE.csv](../licenses/ASSET_PROVENANCE.csv) 记录来源、作者、许可、日期、哈希、是否修改和可否再分发。

第一份 64 秒音乐优先采用可复现的原创合成内容，并保留生成代码、参数和独立时间标注。原创角色保持简单参数化 3D 小精灵；外部 CC0 环境模型也必须保留原始来源并统一材质/光照语言。

用户导入音频不随 Replay 或仓库分发。外部研究数据集只提交获取说明和适配代码，除非已核实再分发权限。AI 辅助生成资源也记录工具来源和人工检查；来源不明的内容不能进入发行包。
